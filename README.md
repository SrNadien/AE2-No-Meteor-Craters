# AE2 No Meteor Craters

Forces all AE2 meteorites to generate with crater type NONE, preventing 
any terrain destruction while keeping the meteorite itself intact.

## Features

- Forces crater type to NONE on every AE2 meteorite via Mixin

## Requirements

⚠️ Must be installed on both client and server.

## Dependencies

- Applied Energistics 2
- GuideME
